# Taste skill v2 reruns

The design-taste-frontend skill ([Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)) shipped v2. These runs repeat the With Taste Skill condition with v2.1.4 (`@6010f91a`). Each rerun replaces that model's earlier With Taste Skill entry in place: same group, same route, same card. The entry carries `skillVersion: "v2"`, which shows a small `v2` label on the card and "With Taste Skill v2" in the skill picker. Entries without the field are v1 runs, recorded in their own benchmark folders.

[provenance.json](provenance.json) records each session, [costs.json](costs.json) the token math, and the `*.source-sha256.json` files the original files before gallery adaptation.

## Shared setup

Every run starts from the same Next.js 16.3.8 / React 19.2.8 starter (`@eeeb008`, lockfile SHA-256 `ce550054…cb915`, unchanged by the runs) with the pinned skill copied into the agent's project skill folder. The prompt is the v1 With Taste Skill prompt with only the dev-server port changed. One prompt, no follow-up coaching, no orchestrator edits to the generated app. Generation happened outside the gallery checkout.
